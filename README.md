## 1. Publish This Portfolio Free on GitHub Pages (3 Steps)
1. Create a public GitHub repository named **`HipolitoB.github.io`** at <https://github.com/new> (leave README unchecked).
2. From inside this folder (`jose-hipolito-baez-portfolio`), run (`origin` is already set to `https://github.com/HipolitoB/HipolitoB.github.io.git`):
   ```powershell
   git push -u origin main
   ```
3. On GitHub → **Settings → Pages → Source: `Deploy from a branch` (`main` / `/root`)**. Your site goes live at **`https://hipolitob.github.io`**.

## 2. Activate Your GitHub Profile Card (`HipolitoB/HipolitoB`)
